# Ajay Kumar Portfolio

Static data engineering portfolio for Ajay Kumar.

## Files
- `index.html`: content and structure
- `styles.css`: visual style and responsive layout
- `script.js`: footer year and reveal animation
- `robots.txt`: crawler rules
- `sitemap.xml`: search engine sitemap

## Run locally
```powershell
python -m http.server 5500
```
Open `http://localhost:5500`.

## Customize
1. Add a LinkedIn or GitHub URL to `index.html` when available.
2. Add a downloadable resume PDF when available.
3. Update `robots.txt` and `sitemap.xml` with the final domain before deployment.
